# Aether Home — Smart Home Dashboard UI

A smart-home web app concept with a dark, editorial UI. Thirteen screens covering the full flow: sign-up, login, password reset, then the app itself (dashboard, devices, scenes, automations, activity logs, energy, security, notifications, add-device pairing, settings).

Built with HTML, Tailwind CSS (CDN) and a small vanilla JS layer (`app.js`) that makes the demo interactive: switches, modes, pairing and read states respond to clicks and persist in the browser. Fonts: Manrope, Inter, Material Symbols.
