# Aether Home — Smart Home Dashboard UI

A smart-home web app concept with a dark, editorial UI. Nine screens covering the full flow: sign-up, login, password reset, then the app itself (dashboard, devices, scenes, automations, activity logs, settings).

Built with HTML and Tailwind CSS (CDN). Fonts: Manrope, Inter, Material Symbols.
